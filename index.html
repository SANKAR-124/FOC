COMPUTER ORGANISATION AND ARCHITECTURE



1. Introduction to Computer Organisation and Architecture

Computer Organization

  • Deals with operational units and interconnections that realize hardware functions.
  • Focuses on how components work together (e.g., control signals, memory interface).

Computer Architecture

  • Concerned with attributes visible to the programmer.
  • Focuses on instruction set, addressing modes, data types.
ASPECT COMPUTER ARCHITECTURE COMPUTER ORGANISATION
Definition Programmer-visible aspects Hardware implementation
Focus Instruction set, memory addressing Control signals, memory types
Concern What a computer does How it does it

2.FUNCTIONAL UNITS OF A COMPUTER

  1. Input Unit - Accepts data (keyboard, mouse).
  2. Output Unit - Displays output (monitor, printer).
  3. memory unit
    • Primary (RAM, ROM)
    • Secondary (HDD, SSD)
  4. Arithmetic and Logic Unit (ALU) – Performs arithmetic & logic operations.
  5. Control Unit (CU) – Directs operations of CPU.
  6. Central Processing Unit (CPU) = ALU + CU
  7. Registers – Small fast storage (accumulator, program counter).

3.BASIC OPERATION CONCEPTS

  • Stored Program Concept – Program instructions stored in memory.
  • Fetch-Decode-Execute Cycle – Basic operation of CPU.
  • Instruction Format – Opcode + operands.

4.Von Neumann Architecture

  • Single memory stores both instructions & data
  • Components: CPU, memory, input/output.
  • Bottleneck: Single bus limits data transfer speed



5.INSTRUCTUON EXECUTION CYCLE

STEP DESCRIPTION
fetch Retrieve instruction from memory
Decode Interpret instruction
execute Perform operation
Store save result

6.REGISTER TRANSFER LANGUAGE

  • Symbolic notation for micro-operations.
  • Example:

    • R2<--R1+R3(ADD R1&R3,STORE IN R3)

7.BUS STRUCTURE

  • Shared communication path among components.
  • Data Bus (bidirectional, transfers data)
  • Address Bus (unidirectional, specifies memory location)
  • Control Bus (bidirectional, carries control signals)

8.MEMORY LOCATIONS AND ADDRESSES

  • Word – Basic unit of data (2/4 bytes).
  • Byte Addressable Memory – Each byte has a unique address
  • Big-Endian – MSB stored at lower address
  • Little-Endian – LSB stored at lower address

9.MEMORY OPERATIONS

  • Read Operation: Memory → CPU
  • Write Operation: CPU → Memory



10.Instruction Format and Types

  • Instruction Format:

    • Opcode + Address/Operands

  • Types of Instructions:
    • Data transfer (MOV)
    • Arithmetic (ADD)
    • Logical (AND)
    • Branch (JMP)
